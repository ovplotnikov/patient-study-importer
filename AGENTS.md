# Инструкции агентам

Общайтесь с пользователем по-русски. Это локальный импортёр медицинских документов для Windows x64.

## Установка или обновление пользователю

Сначала прочитайте `docs/CODEX_INSTALL.md`. Используйте готовый стабильный выпуск официального репозитория `ovplotnikov/patient-study-importer`. Не собирайте исходники и не устанавливайте Python/OCR на компьютер врача для обычной установки.

Работайте только с файлами программы и служебной записью её версии. Для установки/обновления не читайте документы пациентов, базу, таблицы и журналы; не отправляйте их в чат, внешние сервисы, Issues или PR. Не запускайте импорт документов для проверки установки. Не обходите защиту Windows и не завершайте работающую программу принудительно.

## Разработка

Прочитайте `CONTRIBUTING.md` и `docs/PRIVACY.md`. В репозитории, тестах, сообщениях коммитов и артефактах допустимы только вымышленные примеры. Рабочие данные держите вне checkout. Файл с инструкциями не является технической изоляцией доступа к данным: выбирайте рабочую область агента без медицинских документов.

Сохраняйте осторожное сопоставление пациентов и исходный контекст значений. Новое правило разбора проверяйте положительными и отрицательными синтетическими примерами. Не объявляйте поддержку клиники на основании одного распознанного заголовка.

Не включайте печать содержимого документов в CI. Перед коммитом проверьте staged diff и список добавленных файлов. Выпуски создаёт владелец через тег после проверок. Не меняйте видимость репозитория без отдельного решения владельца.
