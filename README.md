# Исследования пациентов

Программа для Windows 10/11 x64: собирает данные из русскоязычных медицинских бланков в одну Excel-таблицу, объединяет исследования одного пациента и помогает проверять неоднозначные результаты.

Обработка выполняется локально. Python и OCR включены в EXE; интернет для обработки не требуется. Программа переносит сведения из документов, не ставит диагнозы и не рассчитывает новые медицинские показатели. Результат нужно сверять с оригиналом, особенно после OCR.

## Скачать и начать

1. Откройте [последний стабильный выпуск](https://github.com/ovplotnikov/patient-study-importer/releases/latest).
2. В **Assets** скачайте **PatientStudyImporter-Windows.zip**. Архивы **Source code** предназначены для разработчиков.
3. Распакуйте ZIP в отдельную папку и откройте **Исследования пациентов.exe**. Python и Tesseract устанавливать не нужно.
4. Выберите рабочую папку, положите документы во **Входящие**, закройте таблицу в Excel и нажмите **Обработать**.
5. Проверьте таблицу, лист **Проверка** и раздел **Уточнить пациентов**.

Репозиторий открыт: готовый выпуск можно скачать без приглашения и аккаунта GitHub. Выпуск программы не содержит рабочих документов пациентов.

## Установка и обновление через Codex

На Windows можно дать агенту такой запрос:

> Установи или обнови «Исследования пациентов» из https://github.com/ovplotnikov/patient-study-importer. Прочитай AGENTS.md и docs/CODEX_INSTALL.md. Используй готовый стабильный выпуск, проверь SHA-256. Сохрани рабочие данные. Для установки не читай и не отправляй документы пациентов. Сообщи установленную версию и расположение программы.

[Инструкция для Codex](docs/CODEX_INSTALL.md) описывает проверку выпуска, установку, обновление и восстановление. Обновление запускается по запросу пользователя; встроенного автоматического обновления сейчас нет. Отдельного проверенного выпуска для macOS/Linux нет.

## Возможности

- PDF с текстом, сканированные и смешанные PDF, DOCX, TXT, JPG/JPEG, PNG, TIFF/TIF и BMP; обработка подпапок.
- Локальное OCR русских и английских печатных текстов.
- Поиск полных ФИО и даты рождения, ручное подтверждение неоднозначных совпадений и личности, распознанной со скана.
- Извлечение лабораторных строк, единиц, референсов, дат, отдельных измерений из описаний и текстовых заключений.
- Дополнение прежней таблицы; обнаружение повторов по SHA-256 и полному тексту с нормализованными пробелами.
- Сохранение оригиналов, ссылок на источники, заметок пользователя и резервных копий.

Листы результата: **Пациенты**, **Исследования**, **Показатели**, **Заключения**, **Проверка**, **Источники**, **Тексты**.

## Какие бланки поддерживаются

Программа использует правила разбора текста и расположения колонок. Это не универсальный распознаватель всех бланков РФ. Определение типа «УЗИ» или «ОАК» само по себе не подтверждает корректность извлечения всех полей.

В [таблице совместимости](docs/SUPPORTED_FORMS.md) описаны форматы, правила извлечения, распознаваемые виды исследований и ограничения. Подтверждённого публичными тестами перечня конкретных клиник пока нет.

## Проверка и сборка для разработчика

Требуется Python 3.12. Из корня проекта:

```text
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

Сборка EXE выполняется на Windows: установить Tesseract OCR на машину сборки, установить `pyinstaller==6.22.3`, выполнить `python packaging/build_windows.py`. После проверок сформировать архив: `python packaging/package_release.py dist`.

GitHub Actions проверяет исходники, собирает EXE и запускает его со встроенным OCR без доступных внешних Python/Tesseract. Тесты используют вымышленные документы. Проверки PR выполняются без разрешения на публикацию релиза. Для выпуска владелец обновляет версию в `patient_importer/__init__.py` и отправляет соответствующий тег `vX.Y.Z`.
