# Исследования пациентов

Программа для Windows 10/11 x64: собирает данные из русскоязычных медицинских бланков в одну Excel-таблицу, объединяет исследования одного пациента и помогает проверять неоднозначные результаты.

Обработка выполняется локально. Python и OCR включены в EXE. Интернет для обработки не требуется. Программа переносит сведения из документов, а медицинскую интерпретацию оставляет врачу. Любой документ, для которого использовалось OCR, остаётся на проверке до ручной сверки.

## Скачать и начать

1. Откройте [последний стабильный выпуск](https://github.com/ovplotnikov/patient-study-importer/releases/latest).
2. В **Assets** скачайте **PatientStudyImporter-Windows.zip**. Архивы **Source code** предназначены для разработчиков.
3. Распакуйте ZIP в отдельную папку и откройте **Исследования пациентов.exe**. Python и Tesseract устанавливать не нужно.
4. Нажмите **Добавить файлы** или перетащите исследования в окно. Закройте таблицу в Excel и нажмите **Обработать**.
5. Если есть замечания, нажмите **Проверить документы**. Сначала уточните пациента, затем сверьте результаты с оригиналом. Откройте таблицу после сверки.

Репозиторий открыт: готовый выпуск можно скачать без приглашения и аккаунта GitHub. Выпуск программы не содержит рабочих документов пациентов.

## Установка и обновление через Codex

На Windows можно дать агенту такой запрос:

> Установи или обнови «Исследования пациентов» из https://github.com/ovplotnikov/patient-study-importer. Прочитай AGENTS.md и docs/CODEX_INSTALL.md. Используй готовый стабильный выпуск, проверь SHA-256. Сохрани рабочие данные. Сообщи установленную версию и расположение программы.

[Инструкция для Codex](docs/CODEX_INSTALL.md) описывает проверку выпуска, установку, обновление и восстановление. Начиная с версии **2.1.0**, программа сама проверяет обновления при запуске. Если доступна новая версия, предлагает установить её и перезапуститься. Установка начинается только после согласия и вне обработки документов; рабочие данные сохраняются. Без интернета программа продолжает работать. Для перехода с 2.0.0 нужно один раз скачать новый EXE вручную или через Codex. Отдельного проверенного выпуска для macOS/Linux нет.

## Возможности

- PDF с текстом, сканированные и смешанные PDF, DOCX, TXT, JPG/JPEG, PNG, TIFF/TIF и BMP; обработка подпапок.
- Локальное OCR печатного текста. Для сканов основной разбор выполняет модель PaddleOCR PP-OCRv5 Cyrillic, а Tesseract rus+eng даёт второе чтение для сверки.
- Поиск полных ФИО и даты рождения. Неоднозначные совпадения и личность, распознанная со скана, требуют подтверждения.
- Извлечение лабораторных строк, единиц, референсов, дат, отдельных измерений и текстовых заключений. Незнакомый тип бланка, пропуски и неоднозначные значения попадают на проверку.
- Сверка с оригиналом и правка показателей и текста заключения перед подтверждением. В таблице видно, какие результаты ещё нужно сверить.
- Дополнение прежней таблицы. Точные копии файла пропускаются. Возможные повторы по неполному или распознанному тексту остаются на ручной проверке.
- Повторное распознавание из сохранённого оригинала с просмотром черновика до применения. Оригиналы, предыдущие результаты сверки и заметки пользователя сохраняются.

В Excel **Исследования** показывают статусы, **Показатели** содержат значения и исходные фрагменты, **Проверка** собирает замечания. Решения записываются на лист **Сверки**.

## Какие бланки поддерживаются

Программа использует правила разбора текста и расположения колонок. Это не универсальный распознаватель всех бланков РФ. Определение типа «УЗИ» или «ОАК» само по себе не подтверждает корректность извлечения всех полей.

В [таблице совместимости](docs/SUPPORTED_FORMS.md) описаны форматы, правила извлечения, распознаваемые виды исследований и ограничения. Подтверждённого публичными тестами перечня конкретных клиник пока нет.

## Проверка и сборка для разработчика

Требуется Python 3.12. Из корня проекта:

```text
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

EXE собирается на Windows. Установите Tesseract OCR на машину сборки и добавьте `pyinstaller==6.22.3` и `reportlab==5.1.0` в окружение Python. Снимите синтетические примеры командой `python app.py --ui-smoke-test build/ui-source`, затем соберите руководство через `python packaging/build_guide.py build/ui-source build/guide` и EXE через `python packaging/build_windows.py`. Скрипт сборки загружает модели с закреплёнными контрольными суммами. После проверок сформируйте архив через `python packaging/package_release.py dist`.

GitHub Actions проверяет исходники, собирает EXE и запускает его со встроенным OCR без доступных внешних Python/Tesseract. Тесты используют вымышленные документы. Проверки PR выполняются без разрешения на публикацию релиза. Для выпуска владелец обновляет версию в `patient_importer/__init__.py` и отправляет соответствующий тег `vX.Y.Z`.

## Проверка документов

В результате обработки у каждого файла свой статус. Через **Проверить документы** сначала сверьте ФИО и дату рождения, затем откройте проверку данных. Слева виден документ, справа — поля и причины проверки. Сверьте значения, знаки, единицы, референсы и заключение. При необходимости исправьте текст или добавьте пропущенную строку. Пропуски в оригинале объясните в замечании.

Для повторного распознавания откройте **Папка данных → Все исследования**. Перед применением сравните текущий результат, новое чтение и то, что будет записано. Ошибку чтения файла можно открыть через **Разобрать** и вернуть файл в очередь через **Повторить**.

Кнопка «Помощь» открывает встроенную визуальную инструкцию со скриншотами без интернета. Она обновляется вместе с EXE. В готовом архиве есть PDF и HTML в папке `docs`.
