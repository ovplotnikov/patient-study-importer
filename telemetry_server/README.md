# Приёмник добровольной диагностики

Приёмник работает на Python 3.12 из корня репозитория. Для него достаточно стандартной библиотеки и общей схемы `patient_importer/telemetry_schema.py`. Он слушает только `127.0.0.1` и предназначен для работы за HTTPS-прокси.

Локальный запуск с отдельным каталогом и списком разрешённых версий:

```sh
python3 -m telemetry_server --database /var/lib/psi-diagnostics/counts.sqlite3 --allow-version 2.4.0
```

На входе `POST /v1/counters` принимает только JSON из общей схемы. Размер ограничен 8192 байтами. Разрешённая версия и минимум 10 попыток в сводке проверяются перед сохранением. Успешный ответ — пустой `204`. Некорректные запросы получают пустой ответ об ошибке. `GET /healthz` возвращает пустой `204` и служит локальной проверкой работы HTTP. Чтение счётчиков через HTTP не предусмотрено.

## Развёртывание

1. Поместите проверенную версию кода в доступный сервису каталог `/opt/patient-study-importer`. Скопируйте `psi-diagnostics.service.example` в `/etc/systemd/system/psi-diagnostics.service`. При необходимости поправьте путь к Python и добавьте повторяющийся параметр `--allow-version` для каждой выпускаемой версии. Не открывайте порт 8765 наружу.
2. Подготовьте отдельный HTTPS-хост с действующим сертификатом. В `nginx.conf.example` замените домен и пути сертификата, затем проверьте конфигурацию командой `nginx -t`. Пример рассчитан на выделенный экземпляр Nginx. Если есть внешний балансировщик, CDN или хостинг, отдельно проверьте отсутствие журналов URL, заголовков, IP и тел запросов.
3. После настройки запустите сервис через systemd и проверьте `curl -fsS -o /dev/null http://127.0.0.1:8765/healthz`. Проверьте TLS, успешный ответ на вымышленный допустимый отчёт и отказ на запрос с лишними полями. Тестовый отчёт отправляйте в отдельную базу. Укажите конечный HTTPS-адрес в конфигурации клиента только после проверки.
4. Доступ к каталогу состояния остаётся у сервиса и администратора. Суммы можно прочитать локально из SQLite, например запросом `SELECT app_version, metric, code, total FROM counters ORDER BY 1, 2, 3;`. Строки старых версий можно удалить административно по версии. Для автоматического срока хранения понадобился бы дополнительный признак периода, сейчас времени поступления в базе нет.

Приёмник не сохраняет запросы, адреса, заголовки, идентификаторы и время отправки. SQLite содержит сумму по разрешённой версии, метрике и коду. Пример Nginx отключает журналирование запросов и запись ошибок прокси. Он пересылает только необходимые служебные заголовки и буферизует допустимые тела в памяти. IP виден сетевому узлу во время соединения. Настройки внешних сервисов и хостинга определяют, что происходит с ним вне приёмника.

Адрес приёма доступен без авторизации. Общие ограничения частоты, размеров и числа соединений сдерживают нагрузку, но не подтверждают происхождение счётчиков. Любой клиент может отправить допустимые значения или повторить отчёт. Эти суммы подходят для ориентировочной диагностики, а их изменения следует подтверждать независимой проверкой. Служебные квоты общие для всех запросов и не учитывают IP.
