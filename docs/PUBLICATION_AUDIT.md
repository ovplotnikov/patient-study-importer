## Как проверяли

1. Получены все доступные refs, просмотрен список объектов истории; проверены имена файлов, текстовые данные, сообщения и авторы коммитов. Все исторические blob декодируются как UTF-8; скрытых бинарных вложений в них не обнаружено.
2. Выполнен поиск сочетаний ФИО, дат, длинных номеров, адресов электронной почты, признаков ключей/токенов и длинных закодированных фрагментов. Срабатывания разобраны по контексту, а не объявлены утечкой автоматически.
3. Выполнена локальная сверка с известными идентификаторами из рабочего набора. Эталонные значения не отправлялись на GitHub. Это дополнительная проверка, а не полный реестр всех возможных пациентов.
4. Через GitHub API с пагинацией собраны метаданные репозитория, комментарии, релизы, runs, artifacts и caches. Скачаны все доступные журналы и артефакты; ZIP проверены на целостность.
5. EXE не запускались для поиска данных. Прочитаны и распакованы таблицы ресурсов PyInstaller, модули PYZ и вложенные архивы. Поиск по одному сжатому EXE не использовался как достаточная проверка.
6. Содержимое скриншотов проверено визуально после группировки одинаковых файлов по SHA-256.

## Разобранные срабатывания

- В исходной истории встречаются **ТЕСТОВ ТЕСТ ТЕСТОВИЧ**, **ПРИМЕРОВ ПРИМЕР ПРИМЕРОВИЧ**, **ВРАЧ ТЕСТ ТЕСТОВИЧ** и тестовые даты **01.01.2000**, **02.03.2025**, **03.03.2025**. Это идентификаторы тестов, не найденные реальные пациенты.
- Длинные числовые строки в метаданных Git — Unix timestamps коммитов. Автор/коммитер исходной истории — `Codex <codex@localhost>`.
- В каждом EXE есть `docx/templates/default.docx`. Это стандартный пустой шаблон библиотеки python-docx: текстовых абзацев пациента нет, SHA-256 совпадает с шаблоном установленной библиотеки. Это не исходное исследование.
- Поиск секретов дал 70 повторных срабатываний в 14 EXE: маркеры форматов приватных ключей в libssh2, строковая таблица Unicode в libunistring и встроенный шрифт Pillow. Разбор содержимого подтвердил, что это служебные ресурсы библиотек, а не ключи доступа. Ещё 14 срабатываний по расширению DOCX относятся к пустому шаблону выше.
- Имена авторов библиотек в лицензиях и имя аккаунта владельца не являются данными пациентов и сохраняются как атрибуция.

Не найдено срабатываний, оставшихся без объяснения в пределах этой проверки.

## Границы результата

Проверка охватывает доступную на эту дату историю и перечисленные материалы. Она не является юридическим заключением или математическим доказательством отсутствия любых персональных данных: поиск по шаблонам, сверка и визуальный просмотр имеют ограничения.

Недоступные удалённые серверные объекты/кэши GitHub, ранее удалённые вложения и чужие копии нельзя исчерпывающе проверить через текущий API. Локальный поиск недостижимых Git-объектов ничего не обнаружил; серверные резервные копии этим не проверяются.

Локальные рабочие исследования и прежний частный комплект с готовыми данными находятся вне репозитория и не являются материалом для публикации. Их нельзя добавлять к открытому выпуску. Не публикуются и локальные эталонные идентификаторы, использованные для сверки.

Новые коммиты, вложения и выпуски требуют собственной проверки: этот отчёт не распространяется на будущие изменения. `.gitignore`, инструкции и шаблоны сообщений снижают риск случайной загрузки, но не заменяют проверку содержимого.

**В ходе проверки видимость не менялась. После ознакомления с отчётом владелец отдельно разрешил публикацию: 7 ноября 2026 года репозиторий переключён в Public. Доступ к выпуску и инструкции без авторизации проверен.**

Количество коммитов и объектов выше относится к снимку завершённой проверки. Последующее изменение этого отчёта и README фиксирует только разрешённое владельцем открытие репозитория и не меняет программу или вложения релиза.
