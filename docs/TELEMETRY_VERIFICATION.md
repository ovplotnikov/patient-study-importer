# Проверка приёмника диагностики

## Обновление для 2.4.1

8 ноября 2026 года действующее развёртывание обновлено до версии 3. URL, таблица, права доступа и формат сообщения сохранены. В разрешённый список добавлена версия 2.4.1; версия 2.4.0 остаётся разрешённой.

SHA-256 кода, считанного из редактора после сохранения, совпал с `google_apps_script/Code.gs`: `9ddbfb00b754086bc3d55a61c17fdb5d2ab9bf5b14448374c975667a0fb86b91`. Интерфейс Apps Script подтвердил публикацию версии 3 на прежнем адресе. GET без входа в Google вернул `{"ok":true}`. Синтетические сообщения с лишним полем для 2.4.0 и 2.4.1 отклонены с `{"ok":false}`.

Восемь локальных тестов приёмника проверяют обе версии и сохранение ранее накопленных сумм. Положительную сводку в рабочие счётчики для этой проверки не добавляли. Сквозная проверка записи в ту же таблицу описана ниже; в этом обновлении изменён только список версий.

## Первичная проверка 2.4.0

7 ноября 2026 года проверен Google Apps Script, развёртывание версии 2, для кандидата приложения 2.4.0. Использованы только вымышленные сводки. Этот отчёт описывает внешний приёмник. Проверки Windows-сборки фиксируются отдельно в [GitHub Actions](https://github.com/ovplotnikov/patient-study-importer/actions/workflows/windows.yml).

SHA-256 проверенного `google_apps_script/Code.gs` — `1339eab6b752c0c00ba9af7b49f9a82aa4bbf2d6f0d73e8bc5470b8d18ad896f`. Публичный адрес приёмника указан в `patient_importer/diagnostics_config.py`.

| Проверка | Результат |
| --- | --- |
| GET по базовому адресу `/exec` без входа в Google | Получено фиксированное подтверждение `{"ok":true}`. |
| Отправка синтетической сводки через `Diagnostics.send_if_due()` | Клиент получил подтверждение за 3,224 с и очистил локальную очередь. В таблице появились ровно две строки итогов — `formats / pdf = 10` и `outcomes / saved = 10`. |
| Лишнее поле, меньше 10 попыток, неизвестный код и параметр запроса | Приёмник отклонил все запросы. Суммы не изменились. |
| Удаление двух тестовых строк | После очистки в таблице остались только заголовки. Общий доступ выключен. В списке разрешений только владелец. |

Проверка подтверждает путь сводки от локального клиента до закрытой таблицы и отказ на перечисленных неверных запросах. Она не охватывает служебные журналы платформы Google. [Состав и условия диагностики](TELEMETRY.md).
