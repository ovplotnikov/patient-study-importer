# Сравнение OCR для русскоязычных бланков

Проверены 30 полностью вымышленных изображений. Скрипт строит три лабораторных макета с разным расположением колонок и шапок. Каждый макет проверяется на чистом изображении, при размытии с уменьшением, наклоне 3,5°, повороте на 90° и слабом контрасте. В отдельной серии меняются шрифт, ФИО, даты, числа и знаки. Например, в ней есть `−12,6`, `≤0,07`, `≥126`, `1.021`, `мкмоль/л` и `10^9/л`. Во второй серии те же семьи макетов, поэтому результаты не показывают качество распознавания новых форм клиник.

Оценивались четыре поля на страницу (тип исследования, ФИО, дата рождения, дата исследования) и три строки. Строка считается точной, только если название показателя, результат со знаком и единица совпали и стоят в нужном порядке **в той же строке**. Сравнение игнорирует регистр и количество пробелов. Разные символы сравнения, десятичные разделители и варианты написания единицы остаются различиями. CER — число вставок, удалений и замен символов, делённое на длину эталона после свёртки пробелов и регистра. Перестановка строк также ухудшает CER.

## Результаты

15 страниц с отдельным шрифтом и значениями, по 60 полей и 45 строк на вариант.

| Вариант | Поля | Строки | Страницы без ошибок в этих полях и строках | CER | Медиана OCR на страницу |
| --- | ---: | ---: | ---: | ---: | ---: |
| Tesseract fast, PSM 3 (как в 2.2.0) | 42/60 | 7/45 | 0/15 | 32,4% | 0,212 с |
| Tesseract best, PSM 3 | 41/60 | 6/45 | 0/15 | 34,6% | 0,390 с |
| Tesseract fast, PSM 6 | 42/60 | 8/45 | 0/15 | 45,5% | 0,199 с |
| PP-OCRv5 eslav, без выравнивания | 59/60 | 8/45 | 1/15 | 22,6% | 0,734 с |
| PP-OCRv5 eslav, с выравниванием | 60/60 | 11/45 | 1/15 | 3,0% | 0,755 с |
| PP-OCRv5 cyrillic, с выравниванием | 60/60 | 17/45 | 3/15 | 2,3% | 0,732 с |

На первой серии Tesseract fast дал 43/60 полей и 10/45 строк, PP-OCRv5 cyrillic с выравниванием — 59/60 полей и 41/45 строк. Разница между сериями показывает чувствительность к шрифту и содержимому. На чистых страницах второй серии Tesseract fast даже распознал больше точных строк (4/9 против 2/9), а на повёрнутых потерял все ключевые поля (0/12 против 12/12). Вариант cyrillic выбран по наибольшему числу точных строк на обеих сериях. Ошибки коротких единиц и знаков сохраняются даже при небольшом CER.

Замер сделан на Apple M6 с Tesseract 5.5.4, RapidOCR 3.10.0, ONNX Runtime 1.19.2 и двумя потоками ONNX. В Windows используются Tesseract 5.5.3 и ONNX Runtime 1.23.2. Время включает распознавание одного изображения после загрузки модели. В приложении второй проход и чтение PDF добавляют время.

## Поведение программы

Основное чтение выполняет PP-OCRv5 cyrillic mobile на CPU. Координаты блоков используются, чтобы выровнять наклонённые строки. При преобладании вертикальных текстовых блоков программа сравнивает чтения после поворота на 90° и 270°. Координаты сохранённого чтения приводятся к исходному изображению. Tesseract fast распознаёт ту же страницу независимо. При различии сохраняются два текста для сверки, а при отказе основного движка используется доступное чтение. Все результаты со сканов требуют подтверждения. Поля двух движков не склеиваются, цифры и единицы не исправляются по догадке.

При сборке модели загружаются по закреплённым адресам с проверкой SHA-256. В готовой программе движки и модели работают локально. Использованные версии и контрольные суммы входят в `build-info.json`.

## Повторить замер

`packaging/benchmark_ocr.py` создаёт изображения в памяти и записывает только агрегируемые показатели. Подготовьте отдельные каталоги `tessdata_fast` и `tessdata_best` с моделями `rus` и `eng`. Для первой серии использованы Arial, для второй Times New Roman. Хэши fast и производственных ONNX-весов закреплены в `packaging/ocr_models.py`. Для best использована [ревизия tessdata_best](https://github.com/tesseract-ocr/tessdata_best/tree/e12c65a915945e4c28e237a9b52bc4a8f39a0cec). Для теста eslav нужен дополнительный файл из [реестра RapidOCR](https://github.com/RapidAI/RapidOCR/blob/main/python/rapidocr/default_models.yaml).

```text
python packaging/benchmark_ocr.py --tesseract /path/to/tesseract \
  --fast /tmp/ocr/fast --best /tmp/ocr/best --onnx /tmp/ocr/onnx --cyrillic \
  --font /path/to/Arial.ttf --holdout-font "/path/to/Times New Roman.ttf" \
  --output /tmp/ocr/results.json
```
