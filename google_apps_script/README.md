# Приёмник счётчиков в Google Drive

Настольная программа отправляет только сводные счётчики. Веб-приложение Apps Script проверяет сообщение и обновляет отдельную приватную таблицу Google. Программа не получает ссылку на таблицу, токен Google или доступ к чтению. Подключение этого варианта требует настройки и проверки владельцем.

## Настройка владельцем

1. Создайте новый самостоятельный проект на [script.google.com](https://script.google.com/). Вставьте `Code.gs` в файл скрипта. В настройках проекта включите отображение манифеста `appsscript.json` и вставьте его содержимое. В списке сервисов должен появиться **Google Sheets API v4**. Если проект использует собственный проект Google Cloud, включите в нём Google Sheets API. [Расширенные сервисы Apps Script](https://developers.google.com/apps-script/guides/services/advanced).
2. В редакторе выберите `initializeSpreadsheet` и выполните один раз под своим аккаунтом. Скрипт создаст отдельную таблицу «Исследования пациентов — диагностика», вкладку «Счётчики» с заголовками и сохранит её ID в **Свойствах скрипта → SPREADSHEET_ID**. Повторный запуск использует сохранённое свойство. ID вводить вручную не нужно. Разрешение `drive.file` даёт приложению доступ к файлам, созданным или явно открытым через него. Этот скрипт создаёт и использует только одну служебную таблицу. [Области доступа Sheets](https://developers.google.com/workspace/sheets/api/scopes).
3. Откройте таблицу на Диске и убедитесь, что общий доступ ограничен. При необходимости переместите её в отдельную приватную папку. Права на таблицу оставьте закрытыми, даже когда URL приёмника доступен пользователям программы.
4. В **Развернуть → Новое развертывание → Веб-приложение** выберите выполнение от имени владельца и доступ «Все», включая посетителей без входа в Google. Некоторые администраторы Google Workspace запрещают такой режим. Скопируйте URL, заканчивающийся на `/exec`. Для настроек клиента нужен этот адрес с окончанием `/v1/counters`, без параметров запроса. [Веб-приложения Apps Script](https://developers.google.com/apps-script/guides/web).

## Проверка развёртывания

Сначала используйте отдельный тестовый проект и таблицу. Подставьте его адрес вместо примера. Оба запроса ниже должны вернуть `{"ok":true}`. Второй отправляет вымышленную сводку, поэтому в таблице появятся две строки по 10. Запрос с лишним полем или меньшим количеством попыток должен вернуть `{"ok":false}` и не изменить счётчики.

```sh
base='https://script.google.com/macros/s/DEPLOYMENT_ID/exec'
curl -fsSL "$base/healthz"
curl -fsSL -H 'Content-Type: application/json' \
  --data-binary '{"app_version":"2.4.0","counters":{"formats":{"pdf":10},"outcomes":{"saved":10}},"schema_version":1}' \
  "$base/v1/counters"
```

Google ContentService отдаёт ответ через одноразовый URL `script.googleusercontent.com`. В приложении тело POST отправляется только на заданный URL, а перенаправление используется для чтения ответа отдельным GET без тела. Приёмник возвращает фиксированный JSON. Код HTTP 200 сам по себе не подтверждает сохранение отчёта. [ContentService и перенаправления](https://developers.google.com/apps-script/guides/content#redirects).

## Что остаётся в таблице

Только четыре колонки: `app_version`, `metric`, `code`, `total`. Каждый отчёт суммируется с текущими значениями. Скрипт проверяет схему, разрешённую версию, порог от десяти попыток и предельный размер 8192 байта до обращения к таблице. На входе требуется компактный ASCII JSON с отсортированными ключами. Такой формат позволяет отклонять повторяющиеся ключи. [Схема диагностики приложения](../docs/TELEMETRY.md).

Скрипт не сохраняет тела запросов, IP, идентификаторы и время отправки. В манифесте отключено журналирование исключений проекта. Google как хостинг и оператор сетевого соединения может обрабатывать сетевые и служебные сведения по своим правилам. [Настройка манифеста](https://developers.google.com/apps-script/manifest).

Приёмник открыт на запись без входа в аккаунт. Посторонний клиент может отправить допустимую сводку и повлиять на суммы или исчерпать квоту. Счётчики подходят для поиска общих проблем. Они не показывают число уникальных пользователей или точность OCR. Отключить приём можно в **Развернуть → Управление развертываниями**.

При подготовке новой версии добавьте её в `WIRE_SCHEMA.versions` и обновите действующее развёртывание. Размер служебной вкладки фиксирован, пересоздавать её для новой версии не нужно. Список допускает до восьми версий. Пока в таблице остаются строки прежней версии, сохраните её в списке. Перед исключением версии владелец может отдельно сохранить её суммы, переместить оставшиеся записи подряд под заголовок и очистить лишние ячейки. Размер вкладки 1024 × 4 должен сохраниться. Скрипт сам старые счётчики не удаляет.

## Локальная проверка кода

```sh
python -m unittest discover -s tests -p test_apps_script.py -v
```

Тесты запускают код в Node.js с имитацией сервисов Google. Они проверяют соответствие общей схеме и запись только агрегатов. Разрешения аккаунта, перенаправления и запись в настоящую таблицу проверяются после развёртывания.
