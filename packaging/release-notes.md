## Версия 2.1.0 — обновления при запуске

Программа автоматически проверяет наличие новой стабильной версии при запуске. Если обновление доступно, предлагает установить его и перезапуститься. Отдельной кнопки в интерфейсе нет. Без интернета работа продолжается; во время обработки документов установка не начинается.

После согласия проверяются SHA-256 архива и EXE, совместимость и запуск новой программы. Прежний EXE сохраняется рядом с суффиксом `.previous.exe`. Рабочая папка, исследования, база, таблица и настройки сохраняются; схема данных не меняется.

**Переход с 2.0.0:** один раз скачайте **PatientStudyImporter-Windows.zip** из Assets, закройте программу, распакуйте архив и замените старый EXE. Папку **Данные** сохраните на прежнем месте. Начиная с 2.1.0 следующие обновления будут предлагаться при запуске.

Готовая программа для Windows 10/11 x64, Python и OCR уже включены. Инструкция и лицензии находятся внутри ZIP. Реальных данных пациентов в выпуске нет.
