Меньше ручной работы: пациент по папке, проверка данных по желанию.

- Документы из одной папки пациента программа относит к этому пациенту, если хотя бы в одном документе этой папки прочитаны полные ФИО и дата рождения. Вводить ФИО для каждого документа больше не нужно. Правило не срабатывает, если в папке документы двух разных пациентов или ФИО прочитано только со скана.
- Можно добавить общую папку с подпапками пациентов, одну папку пациента или отдельные файлы: программа запоминает, в какой папке лежал каждый файл. Подпапка считается отдельной папкой.
- Если ни в одном документе папки нет ФИО, программа спросит один раз на всю папку. В окне видны папка и имя файла, есть кнопки «Открыть файл» и «Показать в папке». Если папка названа полными ФИО с отчеством, они подставятся как заготовка, которую нужно проверить по документу. Дата рождения по-прежнему обязательна.
- Проверка данных больше не обязательна. Документы сразу попадают в таблицу, сомнительные значения и значения со сканов помечены «Не сверено» с причиной. Останавливает только неизвестный пациент. Сверить документ можно, когда удобно, кнопкой «Сверить».
- Если строку таблицы бланка не удалось разобрать, у документа видно, сколько строк не перенесено.
- Числа из описаний без понятного названия больше не выносятся отдельными показателями, текст описания сохраняется. После обновления программа предложит обновить разбор ранее загруженных документов.
- Исправлено: при длинном пути к рабочей папке программа могла потерять папку пациента и сложить документы разных пациентов вместе.

После обновления документы, которые лежали в «Нужно уточнить» только из-за замечаний к данным, переедут в «Обработано». Обновление сохраняет базу, таблицу, заметки, собственные листы и колонки, исходные документы и резервные копии.

Диагностика остаётся добровольной. Состав обезличенных счётчиков расширен: раз в неделю запись об активности без идентификатора, действия в окнах программы, место сбоя в коде без текста ошибки, характеристики компьютера диапазонами. Поэтому программа один раз заново спросит согласие. ФИО, результаты и тексты документов, имена файлов и папок, пути и текст ошибок не отправляются.
